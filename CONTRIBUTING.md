# Request for contributions

Please contribute to this repository if you have ideas on how this app can be expanded or you just want to fix a bug that's been annoying you.

## How to contribute

- **Step 1** - Fork this repository.
- **Step 2** - Clone the repository to your local machine.
- **Step 3** - Add the changes to your repository.
- **Step 4** - Create a PULL Request. And that's all.

## Issues

If you want to contribute something but don't know what, feel free to look at the [Issues Tab](https://github.com/NJCL-Certamen/certamen-questions-app/issues) for desired functionalities and assign yourself to one.
