# certamen-questions-app

This app is meant as a model for those hoping to use [certamen-catalogue](https://github.com/NJCL-Certamen/certamen-catalogue) without creating their own database for the Certamen questions, and for those who want to see an example of how to parse the pseudo-html tags in the questions. This app makes HTTPS GET calls to github to pull down the yaml files directly and then displays them. At some point this project may expand either to model more use-cases or for its use as an app.

You can find the current version of this app running at https://njcl-certamen.github.io/certamen-questions-app/
